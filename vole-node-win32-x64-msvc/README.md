# @zkpass/vole-node-win32-x64-msvc

Native Node addon of the zkPass VOLE-in-the-Head prover and verifier, built for Windows x64.

This package is installed by `@zkpass/vole-node` as an optional dependency on matching platforms
(by `os` and `cpu`), and is not meant to be installed directly. The API (`voleithGenProof`,
`voleithVerifyProofOutputs`) and the byte formats are documented in the
[`@zkpass/vole-node` README](https://www.npmjs.com/package/@zkpass/vole-node).
